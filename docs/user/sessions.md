# Sessions overview

Open **Sessions** from the sidebar or the command palette, or press `mod+alt+s` when the terminal
is not focused. It lists every live thread from all your connected environments on one page:

- **Needs you**: waiting for an approval, an answer, or a plan decision, stopped by a usage limit,
  or ended with an error.
- **Working**: running now.
- **Idle**: everything else, most recent first.

Settled, archived, and snoozed threads are hidden; choose **Snoozed** in the status filter to see
snoozed ones. Filter by project or machine from the top bar. Click a row to open the thread, or use
its buttons to stop or settle it. Right-click a row for the full thread menu.
